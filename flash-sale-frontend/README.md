# Flash Sale Frontend

This folder contains frontend source code

## Prerequisites

- Node installed, check `.nvmrc` for the version.
- Use `fnm use` or `nvm use` to set up the version

## Working folder

All the command below should be run inside `flash-sale-frontend` folder

## Run locally

- Run `npm ci` to install the dependencies
- Run `npm run dev` and open the browser, navigate to `http://localhost:5173`, this should bring up the React default
  page

## Lint and build

- Run `npm run lint` for lint check
- Run `npm run build` to build into `dist/`
